# 股票日K线数据爬取

下载 A 股日K线数据的 Node.js 脚本。**不复权 OHLCV** 来自腾讯财经，**除权除息事件**来自东方财富，脚本据此自行计算后复权因子。

## 功能特点

- 下载日K线（开/收/高/低/成交量），价格为**不复权**原始值
- 用"涨跌幅复权（比例复权）"方法计算**后复权因子 `adj_factor`**，可精确还原日收益率
- 同时输出 **CSV** 与 **Parquet**（Parquet 可直接用 pandas `pd.read_parquet` 读取）
- 自动按 ~6 个月分段抓取，去重、排序、检测交易日缺口
- **增量更新**：已下载过的股票只抓取最后交易日之后的新数据并追加，重复运行幂等
- **自动跳过上市前空白年份**：全量下载时按上市日（东方财富 `f189`）起算，不再从 2000 年空抓
- 自动保存日志

## 使用方法

```bash
node index.js [options]
```

### 参数说明

| 参数 | 别名 | 说明 | 默认值 |
|------|------|------|--------|
| `--codes <list>` | - | 股票代码列表，逗号分隔（如 `sh600519,sz000001`）。省略 `sh/sz` 前缀时自动识别 | - |
| `--date <range>` | - | 日期区间，如 `2020-01-01~2025-12-31`。省略则抓取全部历史 | 全部历史 |
| `--force` | - | 忽略已有文件，重新全量下载（默认增量更新） | - |
| `-h, --help` | - | 显示帮助信息 | - |

### 使用示例

**下载单个股票全部历史：**
```bash
node index.js --codes sh600519
```

**下载指定区间、多个股票：**
```bash
node index.js --codes 600519,000001 --date 2020-01-01~2025-12-31
```

## 输出文件

每个股票输出到 `./data/<code>/` 目录：

| 文件 | 说明 |
|------|------|
| `<code>_kline.csv` | CSV 格式 |
| `<code>_kline.parquet` | Parquet 格式，`pd.read_parquet('<code>_kline.parquet')` |

日志保存到 `./log/marketdata_YYYY-MM-DD.log`。

## 数据字段说明

| 字段名 | 说明 |
|--------|------|
| date | 交易日期 |
| open | 开盘价（不复权） |
| close | 收盘价（不复权） |
| high | 最高价（不复权） |
| low | 最低价（不复权） |
| volume | 成交量 |
| adj_factor | 后复权因子（见下） |

## 复权因子说明

落盘的 OHLCV 均为**不复权**原始价；复权信息单独保存在 `adj_factor` 一列。这样落盘的数据都是**不可变历史**——不复权价永不变，后复权因子也永不变（仅在除权息日跳变），以后只需增量追加新日期。

`adj_factor` 用**涨跌幅复权（比例复权）**方法计算：在每个除权除息日按官方除权参考价跳变，其余日子保持不变（阶梯常数）。`adj_factor` 在最早一行归一为 `1.0`。

除权参考价公式（现金分红 + 送转股 + 配股统一处理）：

```
除权参考价 = (前一交易日收盘价 − 每股现金分红 + 每股配股数 × 配股价) / (1 + 每股送转股数 + 每股配股数)
当日因子   = 前一日因子 × (前一交易日收盘价 / 除权参考价)
```

由此任何复权口径都能现算（一次乘法）：

```python
df['close_hfq'] = df['close'] * df['adj_factor']                       # 后复权
df['close_qfq'] = df['close'] * df['adj_factor'] / df['adj_factor'].iloc[-1]  # 前复权
```

`close × adj_factor` 能**精确还原日收益率**，适合回测/收益计算。

## 注意事项

1. **数据来源**：不复权 OHLCV 来自腾讯财经（`web.ifzq.gtimg.cn`）；现金分红与送转股事件来自东方财富 `datacenter-web.eastmoney.com` 的 `RPT_SHAREBONUS_DET`；配股事件来自东方财富 F10 分红融资接口（`emweb.securities.eastmoney.com/PC_HSF10/BonusFinancing` 的 `pgmx`）。已与多个来源交叉校验，不复权价完全一致。
2. **请求频率限制**：K线抓取已设 1.5 秒间隔、单连接、失败重试，避免被封禁。
3. **配股（rights issue）已处理**：因子公式统一覆盖现金分红、送转股、配股三类事件，已涵盖 A 股全部常见除权除息情形。配股价与配股比例取自 F10 `pgmx`（如"每10股配1.5股"解析为每股 0.15）。
4. **当日数据**：除权息事件与K线均有可能延迟，最新一两个交易日的数据以实际返回为准。
5. **股票代码格式**：支持 A 股 6 位数字代码，自动识别 SH/SZ 交易所。
6. **增量更新**：默认若 `./data/<code>/<code>_kline.csv` 已存在，只从最后交易日起抓取新数据并追加；`adj_factor` 锚定在最早一行（恒为 1.0）、仅在除权息日向后跳变，因此追加新行不会改动历史行的因子。需要重新全量下载时用 `--force`。
7. **上市日起算**：全量下载时先取上市日（东方财富 quote 接口 `f189`），从上市日而非 2000 年开始分段抓取，避免对上市前年份发出大量空请求。取不到上市日时回退到 2000-01-01。`--date` 指定了更晚的起始日则以其为准。
