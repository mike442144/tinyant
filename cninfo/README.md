# 巨潮资讯网年度报告下载器

从巨潮资讯网（cninfo.com.cn）爬取A股上市公司年度报告（PDF），支持按年份范围批量下载。

## 功能特点

- 支持按年份范围下载年度报告（如 `--year 2020-2025`）
- PDF文件名包含公司简称，便于识别（如 `2023_贵州茅台_年度报告.pdf`）
- 按股票代码分目录存储
- 支持断点续传：已下载的PDF会自动跳过
- 自动过滤非主报告（摘要、英文版、更正公告等）
- 生成下载汇总CSV

## 安装依赖

```bash
npm install
```

需要的依赖包已在根目录 `package.json` 中定义。

## 使用方法

### 基本命令

```bash
node index.js [options]
```

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--file <path>` | 股票代码文件路径（每行一个代码，#开头为注释） | - |
| `--codes <list>` | 股票代码列表，逗号分隔 | - |
| `--year <range>` | 财年范围，如 `2020-2025` 或单年 `2023`（按报告年度筛选，非发布日期） | 当前年份 |
| `-h, --help` | 显示帮助信息 | - |

### 使用示例

**下载单只股票指定年份范围的年度报告：**
```bash
node index.js --codes 600519 --year 2020-2025
```

**下载多只股票的年度报告：**
```bash
node index.js --codes 600519,000858 --year 2023-2024
```

**从文件读取股票代码列表：**
```bash
# stocks.txt 内容：
# 600519
# 000858
# 002749

node index.js --file stocks.txt --year 2020-2025
```

**下载单年报告：**
```bash
node index.js --codes 600519 --year 2023
```

## 输出文件

### PDF文件
- 路径：`./data/<股票代码>/`
- 命名格式：`<年份>_<公司简称>_年度报告.pdf`

示例目录结构：
```
./data/
  600519/
    2022_贵州茅台_年度报告.pdf
    2023_贵州茅台_年度报告.pdf
  000858/
    2022_五粮液_年度报告.pdf
    2023_五粮液_年度报告.pdf
```

### 汇总CSV
- 路径：`./data/cninfo_annual_reports_YYYY-MM-DD.csv`
- 编码：UTF-8 with BOM

| 字段 | 说明 |
|------|------|
| code | 股票代码 |
| secName | 公司简称 |
| year | 报告年度 |
| title | 公告原标题 |
| fileName | 保存文件名 |
| fileSize | 文件大小（字节） |
| downloadTime | 下载时间 |

### 日志文件
- 路径：`./log/`
- 格式：`cninfo_YYYY-MM-DD.log`

## 注意事项

1. **请求频率限制**：脚本已设置10秒请求间隔，避免被网站封禁
2. **数据来源**：数据来源于巨潮资讯网（中国证监会指定信息披露平台），仅供参考
3. **股票代码格式**：支持A股6位数字代码，自动识别沪深交易所（0/3开头为深交所，其余为上交所）
4. **报告过滤**：自动排除标题中包含"摘要"、"英文"、"更正"、"补充"、"已取消"的公告
5. **断点续传**：重复运行时，已存在的PDF文件会自动跳过，不会重复下载
6. **大文件超时**：PDF下载超时设置为120秒，以应对较大的年度报告文件
