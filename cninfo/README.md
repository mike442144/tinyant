# 巨潮资讯网公告/年度报告下载器

从巨潮资讯网（cninfo.com.cn）爬取A股上市公司公告/年度报告（PDF），支持按年份、关键词、分类筛选。

## 功能特点

- **年度报告模式**：按财年范围下载年度报告（如 `--year 2020-2025`），自动过滤摘要/更正等非主报告
- **通用公告模式**：按发布日期范围、关键词、分类下载任意公告
- PDF文件名包含公司简称，便于识别（如 `2023_贵州茅台_年度报告.pdf`）
- 按股票代码分目录存储
- 支持断点续传：已下载的PDF会自动跳过
- 支持 `--list` 预览模式，不下载只列出结果
- 生成下载汇总CSV


## 使用方法

### 基本命令

```bash
node index.js [options]
```

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--file <path>` | 股票代码文件路径（每行一个代码，#开头为注释） | - |
| `--codes <list>` | 股票代码列表，逗号分隔 | - |
| **年度报告模式** | | |
| `--annual` | 仅下载年度报告 | - |
| `--year <range>` | 财年范围，如 `2020-2025` 或单年 `2023`（按报告年度筛选，非发布日期） | 当前年份 |
| **通用公告模式** | | |
| `--date <range>` | 发布日期范围，如 `2025-01-01~2025-06-30` | 近一个月 |
| `--category <code>` | 分类代码，常见值见下方 | 全部分类 |
| `--keyword <text>` | 标题关键词搜索 | - |
| **通用参数** | | |
| `--pdf-only` | 仅下载PDF格式（跳过HTML） | - |
| `--list` | 仅列出结果，不下载 | - |
| `--count <n>` | 每只股票最多返回数（上限500） | 30 |
| `-h, --help` | 显示帮助信息 | - |

### 常用分类代码

| 代码 | 含义 |
|------|------|
| `category_ndbg_szsh` | 年度报告 |
| `category_bndbg_szsh` | 半年度报告 |
| `category_yjdbg_szsh` | 一季度报告 |
| `category_sjdbg_szsh` | 三季度报告 |
| `category_rcgg_szsh` | 日常公告 |

### 使用示例

**年度报告：下载单只股票指定财年范围：**
```bash
node index.js --codes 600519 --annual --year 2020-2025
```

**年度报告：下载多只股票：**
```bash
node index.js --codes 600519,000858 --annual --year 2023-2024
```

**通用公告：按关键词搜索（预览）：**
```bash
node index.js --codes 600519 --keyword 分红 --list --date 2024-01-01~2024-12-31
```

**通用公告：按分类下载PDF：**
```bash
node index.js --codes 600519 --category category_bndbg_szsh --pdf-only
```

**从文件读取股票代码列表：**
```bash
# stocks.txt 内容：
# 600519
# 000858

node index.js --file stocks.txt --annual --year 2020-2025
```

## 输出文件

### PDF文件
- 路径：`./data/<股票代码>/`
- 年度报告命名：`<年份>_<公司简称>_年度报告.pdf`
- 通用公告命名：`<发布日期>_<公告标题>.pdf`

示例目录结构：
```
./data/
  600519/
    2022_贵州茅台_年度报告.pdf
    2023_贵州茅台_年度报告.pdf
    2024-11-09_贵州茅台2024年中期利润分配方案公告.pdf
```

### 汇总CSV
- 年度报告路径：`./data/cninfo_annual_reports_YYYY-MM-DD.csv`
- 通用公告路径：`./data/cninfo_YYYY-MM-DD.csv`
- 编码：UTF-8 with BOM

| 字段 | 说明 |
|------|------|
| code | 股票代码 |
| secName | 公司简称 |
| date | 年度报告为财年（如 2023），通用公告为发布日期 |
| title | 公告原标题 |
| fileType | 文件类型（PDF/HTM） |
| fileName | 保存文件名 |
| fileSize | 文件大小（字节） |
| downloadTime | 下载时间 |

### 日志文件
- 路径：`./log/`
- 格式：`cninfo_YYYY-MM-DD.log`

## 注意事项

1. **请求频率限制**：脚本已设置10秒请求间隔，避免被网站封禁
2. **数据来源**：数据来源于巨潮资讯网（中国证监会指定信息披露平台），仅供参考
3. **股票代码格式**：支持A股6位数字代码，自动识别沪深交易所（0/3开头为深交所，其余为上交所）
4. **年度报告过滤**：自动排除标题中包含"摘要"、"英文"、"更正"、"补充"、"已取消"的公告
5. **断点续传**：重复运行时，已存在的PDF文件会自动跳过；年度报告模式会直接跳过API请求
6. **大文件超时**：PDF下载超时设置为120秒
7. **通用模式分页**：单只股票最多返回500条，超过请使用更窄的日期范围或分类过滤
