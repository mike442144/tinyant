# 地块信息查询（全国城市）

查询各城市土地出让/成交地块详情（面积、用途、成交价、竞得人等），用于房企拿地研究工作流：配合 cninfo/hkexnews 模块下载的房企月度经营公告，核实公告中披露的新拿地信息。

## 功能特点

- **北京**：直连北京市规划和自然资源委员会土地市场 JSON API
- **深圳**：直连深圳公共资源交易中心 JSON API（结果公示 + 出让公告）
- **杭州**：直连杭州市规划和自然资源局成交结果公示（JCMS API，竞得入选公示）
- **成都**：直连成都公共资源交易中心土地交易结果（拍卖会/挂牌会结果一览表）
- **苏州**：直连苏州公共资源交易中心成交公示（JSON API，覆盖市区+张家港）
- **常熟**：直连苏州公共资源交易平台常熟分中心成交公示（JSON API）
- **昆山**：直连昆山市人民政府土地成交公告（静态页，22页共325条）
- **太仓**：直连苏州公共资源交易平台太仓分中心成交公示（JSON API）
- **吴江**：直连江苏土地市场网 landjs.com（JSON API，按成交日期服务端过滤，响应含全字段）
- **其他任意城市**（上海/广州等一二三四线均可）：自然资源部中国土地市场网（landchina.mnr.gov.cn）挂牌出让成交公示，全国静态页遍历 + 城市/关键词过滤
- 字段归一化：面积统一为平方米（公顷/亩自动换算），价格统一为万元（亿元自动换算，成都单价元/平方米按面积折算总价）
- 支持 `--list` 预览模式
- 结果输出为 CSV

## 使用方法

在 `landinfo/` 目录下运行：

```bash
node index.js --city <城市> --keyword <关键词> [options]
```

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--city <name>` | 城市名，任意城市均可，如 北京/深圳/苏州/杭州（必填） | - |
| `--keyword <text>` | 宗地编号或位置关键词（必填） | - |
| `--date <range>` | 日期范围，如 `2026-01-01~2026-08-31` | 近一个月 |
| `--list` | 仅列出匹配结果，不抓取详情 | - |
| `--pageSize <n>` | 每页条数 | 20 |
| `-h, --help` | 显示帮助信息 | - |

### 使用示例

**北京：按文号预览挂牌公告：**
```bash
node index.js --city 北京 --keyword 京土储挂 --list
```

**深圳：按宗地号查成交详情：**
```bash
node index.js --city 深圳 --keyword G13111-0115 --date 2026-07-01~2026-08-31
```

**上海/广州：按位置关键词查成交公示：**
```bash
node index.js --city 上海 --keyword 浦东 --date 2026-08-01~2026-08-05
node index.js --city 广州 --keyword AT090924 --date 2026-08-01~2026-08-05
```

**杭州：按公告文号查竞得入选公示：**
```bash
node index.js --city 杭州 --keyword 杭政储出 --date 2026-06-01~2026-08-05
```

**成都：按宗地编号查成交结果：**
```bash
node index.js --city 成都 --keyword CH05 --date 2026-07-01~2026-08-05
```

**苏州/常熟/昆山/太仓：按宗地编号查成交公示：**
```bash
node index.js --city 苏州 --keyword 苏地2026-WG-Z06 --date 2026-04-01~2026-05-01
node index.js --city 常熟 --keyword 2026G009 --date 2026-03-01~2026-04-01
node index.js --city 昆山 --keyword 住挂字3号 --date 2026-07-01~2026-08-06
node index.js --city 太仓 --keyword 2026-WG-13 --date 2026-07-01~2026-08-06
```

**吴江：按宗地编号查成交（江苏土地市场网，按成交日期过滤）：**
```bash
node index.js --city 吴江 --keyword WJ-G-2026-021 --date 2026-06-01~2026-08-06
```

**其他城市（landchina 通道）：**
```bash
node index.js --city 上海 --keyword 松江 --date 2026-07-01~2026-08-05
```

## 输出文件

### 结果CSV
- 路径：`./data/landinfo_<城市>_YYYY-MM-DD.csv`
- 编码：UTF-8 with BOM

| 字段 | 说明 |
|------|------|
| city | 城市 |
| parcelId | 宗地编号 |
| location | 地块位置 |
| area | 出让面积（平方米） |
| purpose | 土地用途 |
| price | 价格（万元）：北京/深圳成交价为0或空表示未成交，深圳出让公告为挂牌起始价 |
| buyer | 竞得人/受让人 |
| dealDate | 公告/成交日期 |
| noticeType | 公告类型（挂牌出让公告/结果公示/成交公示等） |
| title | 公告标题 |
| source | 数据来源 |
| sourceUrl | 详情链接 |

### 日志文件
- 路径：`./log/landinfo_YYYY-MM-DD.log`

## 注意事项

1. **请求频率**：单连接 + 3秒请求间隔，避免被政府网站封禁
2. **landchina 通道覆盖范围**：北京/深圳/杭州/成都/苏州/常熟/昆山/太仓/吴江以外的城市均走自然资源部中国土地市场网的成交公示，覆盖招拍挂成交结果；协议出让等非招拍挂方式不在此列。上海/广州本地交易中心站点有反爬（TLS 旧协议/JS 校验），故同样走此通道
3. **苏州全域覆盖**：`--city 苏州` 覆盖市区+张家港；常熟/太仓走苏州交易平台对应分中心（`--city 常熟`/`--city 太仓`）；昆山走市政府官网（`--city 昆山`）；吴江走江苏土地市场网（`--city 吴江`）。注意 landjs 上 price=0 的记录多为划拨/协议出让
4. **日期范围影响耗时**：landchina 通道按全国成交公示倒序翻页（每页25条，全国每日约25页），日期范围越宽抓取越慢，建议控制在两周内
5. **北京在途地块**：挂牌中的地块成交价/竞得人为空，需待成交后重查
6. **深圳关键词匹配**：服务端为完整短语匹配，未命中时自动退回客户端过滤（扫描日期范围内全部土地矿业公告，上限30页）
7. **杭州为竞得入选公示**：资格审查前的"竞得入选人"，非最终成交确认（备注中会注明资格审查期限）；面积原始单位为亩，已自动换算为平方米
8. **成都走交易中心而非规自局**：成都市规自局官网（mpnr.chengdu.gov.cn）有 WAF 拦截，故改用成都公共资源交易中心；列表翻页依赖 ASP.NET postback（VIEWSTATE 隐藏字段），站点改版可能导致翻页失效；关键词在详情页正文匹配（标题不含宗地编号），翻页上限 20 页；成交价多为单价（元/平方米），已按面积折算为总价万元
9. **苏州平台接口怪癖**：ggzy.suzhou.gov.cn 的 getDetailPath 必须带 `pageIndex=0` 否则报验证码错误；`pageIndex>=10` 强制验证码（与 pageSize 无关），且 pageSize>1 的二级索引滞后、会漏最新记录。故采用两段式翻页：pageSize=1 扫前 9 页拿最新记录，未达日期下限时切 pageSize=10 深翻 9 页（按 infoid 去重），可覆盖最近约 90 条公示；更早记录需缩小日期范围分段查询。详情页偶发 WAF 502，自动重试 3 次
