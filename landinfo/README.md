# 一线城市地块信息查询

查询北上广深土地出让/成交地块详情（面积、用途、成交价、竞得人等），用于房企拿地研究工作流：配合 cninfo/hkexnews 模块下载的房企月度经营公告，核实公告中披露的新拿地信息。

## 功能特点

- **北京**：直连北京市规划和自然资源委员会土地市场 JSON API
- **深圳**：直连深圳公共资源交易中心 JSON API（结果公示 + 出让公告）
- **上海/广州**：自然资源部中国土地市场网（landchina.mnr.gov.cn）挂牌出让成交公示，全国静态页遍历 + 关键词过滤
- 字段归一化：面积统一为平方米（公顷自动换算），价格统一为万元（亿元自动换算）
- 支持 `--list` 预览模式
- 结果输出为 CSV

## 使用方法

在 `landinfo/` 目录下运行：

```bash
node index.js --city <城市> --keyword <关键词> [options]
```

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--city <name>` | 城市：北京/上海/广州/深圳（必填） | - |
| `--keyword <text>` | 宗地编号或位置关键词（必填） | - |
| `--date <range>` | 日期范围，如 `2026-01-01~2026-08-31` | 近一个月 |
| `--list` | 仅列出匹配结果，不抓取详情 | - |
| `--pageSize <n>` | 每页条数 | 20 |
| `-h, --help` | 显示帮助信息 | - |

### 使用示例

**北京：按文号预览挂牌公告：**
```bash
node index.js --city 北京 --keyword 京土储挂 --list
```

**深圳：按宗地号查成交详情：**
```bash
node index.js --city 深圳 --keyword G13111-0115 --date 2026-07-01~2026-08-31
```

**上海/广州：按位置关键词查成交公示：**
```bash
node index.js --city 上海 --keyword 浦东 --date 2026-08-01~2026-08-05
node index.js --city 广州 --keyword AT090924 --date 2026-08-01~2026-08-05
```

## 输出文件

### 结果CSV
- 路径：`./data/landinfo_<城市>_YYYY-MM-DD.csv`
- 编码：UTF-8 with BOM

| 字段 | 说明 |
|------|------|
| city | 城市 |
| parcelId | 宗地编号 |
| location | 地块位置 |
| area | 出让面积（平方米） |
| purpose | 土地用途 |
| price | 价格（万元）：北京/深圳成交价为0或空表示未成交，深圳出让公告为挂牌起始价 |
| buyer | 竞得人/受让人 |
| dealDate | 公告/成交日期 |
| noticeType | 公告类型（挂牌出让公告/结果公示/成交公示等） |
| title | 公告标题 |
| source | 数据来源 |
| sourceUrl | 详情链接 |

### 日志文件
- 路径：`./log/landinfo_YYYY-MM-DD.log`

## 注意事项

1. **请求频率**：单连接 + 3秒请求间隔，避免被政府网站封禁
2. **上海/广州走全国站点**：本地交易中心站点有反爬（TLS 旧协议/JS 校验），故采用自然资源部中国土地市场网的成交公示，覆盖招拍挂成交结果；协议出让等非招拍挂方式不在此列
3. **日期范围影响耗时**：上海/广州模式按全国成交公示倒序翻页（每页25条，全国每日约25页），日期范围越宽抓取越慢，建议控制在两周内
4. **北京在途地块**：挂牌中的地块成交价/竞得人为空，需待成交后重查
5. **深圳关键词匹配**：服务端为完整短语匹配，未命中时自动退回客户端过滤（扫描日期范围内全部土地矿业公告，上限30页）
