# 港交所披露易年度报告下载器

从 hkexnews.hk（港交所披露易）爬取港股上市公司年度报告（PDF），支持按年份范围批量下载。

## 功能特点

- 支持按财年范围下载年度报告（如 `--year 2020-2025`）
- PDF文件名包含公司繁体中文简称（如 `2024_騰訊控股_年度报告.pdf`）
- 按股票代码分目录存储
- 支持断点续传：已下载的PDF会自动跳过
- 仅下载PDF格式的年报，自动过滤HTML格式
- 生成下载汇总CSV

## 安装依赖

```bash
npm install
```

需要的依赖包已在根目录 `package.json` 中定义。

## 使用方法

### 基本命令

```bash
node index.js [options]
```

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--file <path>` | 股票代码文件路径（每行一个代码，#开头为注释） | - |
| `--codes <list>` | 股票代码列表，逗号分隔（5位代码，如 00700） | - |
| `--year <range>` | 财年范围，如 `2020-2025` 或单年 `2023`（按报告年度筛选） | 当前年份 |
| `-h, --help` | 显示帮助信息 | - |

### 使用示例

**下载单只股票指定年份范围的年度报告：**
```bash
node index.js --codes 00700 --year 2020-2025
```

**下载多只股票的年度报告：**
```bash
node index.js --codes 00700,09988,02858 --year 2023-2024
```

**从文件读取股票代码列表：**
```bash
# hk_stocks.txt 内容：
# 00700
# 09988
# 02858

node index.js --file hk_stocks.txt --year 2020-2025
```

## 输出文件

### PDF文件
- 路径：`./data/<股票代码>/`
- 命名格式：`<年份>_<公司繁体中文简称>_年度报告.pdf`

示例目录结构：
```
./data/
  00700/
    2023_騰訊控股_年度报告.pdf
    2024_騰訊控股_年度报告.pdf
  02858/
    2019_易鑫集團_年度报告.pdf
    2020_易鑫集團_年度报告.pdf
```

### 汇总CSV
- 路径：`./data/hkexnews_annual_reports_YYYY-MM-DD.csv`
- 编码：UTF-8 with BOM

| 字段 | 说明 |
|------|------|
| code | 股票代码 |
| secName | 公司简称（繁体中文） |
| year | 报告年度 |
| title | 公告原标题 |
| fileName | 保存文件名 |
| fileSize | 文件大小（字节） |
| downloadTime | 下载时间 |

### 日志文件
- 路径：`./log/`
- 格式：`hkexnews_YYYY-MM-DD.log`

## 数据来源

数据来自港交所披露易（hkexnews.hk），为香港交易所官方信息披露平台，年报覆盖完整。API无需认证。

## 注意事项

1. **请求频率限制**：脚本已设置10秒请求间隔，避免触发Akamai机器人检测
2. **股票代码格式**：港股代码为5位数字（含前导零），如 00700（腾讯）、09988（阿里巴巴）
3. **公司名称**：使用繁体中文简称（来自港交所官方股票列表）
4. **报告过滤**：仅下载PDF格式的年度报告（通过 t1code=40000, t2code=40100 过滤）
5. **断点续传**：重复运行时，已存在的PDF文件会自动跳过
6. **大文件超时**：PDF下载超时设置为120秒
