# 港交所披露易下载器

从 hkexnews.hk（港交所披露易）下载港股上市公司公告和年度报告（PDF），支持按类别、关键词、日期范围过滤。

## 功能特点

- **年度报告模式**：按财年范围批量下载年度报告
- **公告模式**：按类别、关键词、日期范围下载任意公告
- `--list` 预览模式：查看结果不下载
- PDF文件名包含公司繁体中文简称
- 按股票代码分目录存储
- 断点续传：已下载文件自动跳过
- 生成下载汇总CSV

## 安装依赖

```bash
npm install
```

## 使用方法

### 年度报告模式

使用 `--annual` 和 `--year` 下载年度报告：

```bash
node announcement.js --codes 00700 --annual --year 2020-2025
node announcement.js --codes 00700,09988 --annual --year 2023-2024
node announcement.js --file hk_stocks.txt --annual --year 2024
```

### 公告模式

按类别、关键词、日期范围下载公告：

```bash
# 查看腾讯最近公告（预览）
node announcement.js --codes 00700 --list

# 下载腾讯财务报表类公告
node announcement.js --codes 00700 --category 40000 --pdf-only

# 搜索含"業績"的公告
node announcement.js --codes 00700 --keyword 業績 --pdf-only

# 指定日期范围
node announcement.js --codes 00700 --date 20250101-20250630 --count 50
```

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--file <path>` | 股票代码文件路径（每行一个代码，#开头为注释） | - |
| `--codes <list>` | 股票代码列表，逗号分隔（5位代码，如 00700） | - |
| **年度报告模式** | | |
| `--annual` | 仅下载年度报告 | - |
| `--year <range>` | 财年范围，如 `2020-2025` 或单年 `2023` | 当前年份 |
| **公告模式** | | |
| `--date <range>` | 日期范围，如 `20250101-20250630` | 最近一个月 |
| `--category <code>` | Tier 1 类别代码（见下表） | 全部 |
| `--keyword <text>` | 标题关键词搜索 | - |
| **通用** | | |
| `--pdf-only` | 仅下载PDF文件 | - |
| `--list` | 预览结果不下载 | - |
| `--count <n>` | 每只股票最大结果数 | 30 |

### 类别代码

| 代码 | 名称 |
|------|------|
| 10000 | 公告及通告 |
| 20000 | 通函 |
| 30000 | 上市文件 |
| 40000 | 财务报表/ESG |
| 50000 | 翌日披露报表 |
| 51500 | 月报表 |

## 输出文件

### 年度报告文件
- 路径：`./data/<股票代码>/`
- 命名格式：`<年份>_<公司简称>_年度报告.pdf`

### 公告文件
- 路径：`./data/<股票代码>/`
- 命名格式：`<日期>_<标题截断>.<pdf|htm>`

### 汇总CSV
- 路径：`./data/hkexnews_ann_YYYY-MM-DD.csv`

## 注意事项

1. **请求频率**：10秒请求间隔，避免触发Akamai机器人检测
2. **股票代码**：港股5位数字（含前导零），如 00700（腾讯）、09988（阿里巴巴）
3. **公司名称**：繁体中文（来自港交所官方股票列表）
4. **断点续传**：重复运行时已存在的文件自动跳过，全部已下载时零网络请求
5. **数据来源**：港交所披露易（hkexnews.hk），API无需认证
